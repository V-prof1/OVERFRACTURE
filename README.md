# OVERFRACTURE

Mobile-first incremental roguelite survival feito em HTML/CSS/JavaScript.

## Web Prototype 0.1

- Fracture Core clicável com crítico e multiplicador global
- Flux, Shards e sistema de Fracture/Rebirth
- 4 upgrades permanentes/de progressão
- Produção automática de Flux
- Runs top-down de 90 segundos
- Movimento por toque/arrasto no mobile e WASD no PC
- Auto-fire, dash, hordas progressivas e inimigos elite
- Boss aos 60 segundos
- XP, level-up e escolhas aleatórias de mutações durante a run
- Recompensas de Flux e Shards ao final
- Save local via `localStorage`
- Interface responsiva sem assets externos

## Rodar

O jogo é estático. Abra via GitHub Pages ou qualquer servidor HTTP simples.
